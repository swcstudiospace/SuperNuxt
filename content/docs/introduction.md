SuperNuxt is a Nuxt 4 framework. Install it and the dev server opens a white and emerald landing page, with this documentation site beside it and a studio for the TanStack libraries.

The package is a Nuxt layer. A new app extends that layer, so the landing page, the docs, and the studio ship with the framework. You add pages only when you are ready to replace a default.

## What you get

- Nuxt 4.6, Vue 3, and Nitro server routes.
- The TanStack Vue libraries, wired and auto-imported.
- An Rstack toolchain for tests, lint, the library build, and docs.
- One logo, used as the favicon, the header mark, and the install artwork.
- A scaffolder that runs from npm, pnpm, Bun, npx, and Deno.

## Where to go next

Start with [installation](/docs/installation) if you are creating an app. Read [the module](/docs/module) if you are adding SuperNuxt to a Nuxt app you already have. The [studio](/studio) is the live reference for Query, DB, AI, Table, and the rest.
