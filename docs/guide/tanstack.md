# TanStack

The module installs Vue Query with SSR dehydrate and hydrate. Pages in the studio exercise the other libraries directly.

| Library                                              | How SuperNuxt uses it                                                 |
| ---------------------------------------------------- | --------------------------------------------------------------------- |
| Query                                                | Plugin, devtools panel, manifest bench                                |
| DB                                                   | Local collection and live query                                       |
| Store                                                | Deck preferences                                                      |
| AI                                                   | `useChat` plus a local text adapter                                   |
| Table, Form, Charts, Virtual, Pacer, Hotkeys, Ranger | Studio benches                                                        |
| Router                                               | Memory-history island beside Nuxt file routes                         |
| Markdown, Highlight                                  | Prose lab                                                             |
| Start                                                | Named server functions on Nitro. Start itself targets React and Solid |
| Devtools                                             | Shell dock                                                            |
| Config, CLI, Intent                                  | Tooling packages and the agent skill                                  |
