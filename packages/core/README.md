# @swcstudio/supernuxt-core

Framework-agnostic SuperNuxt domain code: the TanStack/Rstack stack catalog,
mission ledger, typed server-function contracts, docs parsing and release helpers.

```sh
npm i @swcstudio/supernuxt-core          # npm
deno add jsr:@swcstudiospace/supernuxt-core   # Deno / JSR
```

The Nuxt layer is `supernuxt` and the module is `@swcstudio/supernuxt-nuxt` (npm only).
