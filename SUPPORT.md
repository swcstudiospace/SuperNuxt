# Support

SuperNuxt is the source repository at [github.com/swcstudiospace/SuperNuxt](https://github.com/swcstudiospace/SuperNuxt).

## Questions and bugs

Open a GitHub issue:

<https://github.com/swcstudiospace/SuperNuxt/issues/new/choose>

Use the bug or feature template. Include the SuperNuxt version from the root `package.json` (`0.2.0` in this checkout), the Node.js version, and the command you ran.

GitHub Discussions are disabled on this repository. This repository does not document a chat channel or a forum.

## Security

Do not report a vulnerability in a public issue. Use a private GitHub Security Advisory:

<https://github.com/swcstudiospace/SuperNuxt/security/advisories/new>

The supported versions and what to include are in [SECURITY.md](./SECURITY.md).

## Changes and merges

Behavior changes are recorded in [CHANGELOG.md](./CHANGELOG.md). Contribution steps are in [CONTRIBUTING.md](./CONTRIBUTING.md).

Ming merges pull requests. Review requests go to the owners in [CODEOWNERS](./CODEOWNERS).
